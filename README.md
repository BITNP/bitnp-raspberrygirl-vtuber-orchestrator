# Raspberry Girl VTuber Orchestrator

Orchestrator 是 Raspberry Girl 分布式 AI VTuber 系统的中心仓库，也是整个项目的总览文档入口。它拥有规范协议、会话状态、调度器、ASR/LLM/TTS provider 边界、现场讲解音频桥接，以及跨模块契约验证脚本。

系统级、概览性、协议权威和部署编排文档写在本仓库；Mic、Sound、Comments、Frontend 的模块专属文档写在各自仓库内。
