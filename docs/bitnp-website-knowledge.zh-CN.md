# 网站知识库快照

`knowledge/bitnp-website/` 是从本地 `bitnp-website` 提取的72份中文 Markdown，可直接由 Orchestrator 的离线知识库加载。内容包括协会简介、5个部门介绍、8项服务、公开联系方式、3份历史指南/招新资料和校园导航。每份资料保留源文件路径；来源提交、源文件及产物 SHA-256 见 [来源清单](bitnp-website-knowledge.manifest.json)。提取日期为2026-09-14。

## 使用

从 Orchestrator 仓库根目录启动时，在本地环境配置中设置：

```dotenv
ORCHESTRATOR_KNOWLEDGE_DIR=knowledge/bitnp-website
ORCHESTRATOR_KNOWLEDGE_TOP_K=4
```

其他工作目录或容器部署请使用部署后语料目录的绝对路径。只部署 `knowledge/bitnp-website/` 中的语料；来源清单和本说明留在目录外，避免参与检索。配置后重启 Orchestrator；后续语料更新同样需要重启。加载器根据文件路径和内容自动生成语料版本，无需另建数据库或下载嵌入模型。

## 提取范围与取舍

- 以路由实际引用的 `home3.vue`、`aboutUs.vue`、`Common-Links.vue` 和公共页脚为来源；不导入旧首页、代码、CSS、图片、第三方依赖和占位时间线。
- 人工整理协会与服务介绍，保留关键词和产品名称，统一协会全称。部门页面没有更新时间，明确标为旧版介绍；电脑诊所旧地址不作为当前地址确认。
- 2025招新、2025电脑指南、2022校园网指南保留原始日期和链接，仅收录网站摘要。未抓取微信公众号、腾讯文档及其他外部链接正文，也没有验证链接实时可用性。
- 不导入无日期的人员规模、关注人数、“最大”“唯一”等宣传性现状断言，不使用2024迎新群作为当前联系方式。2022活动排期没有作为未来活动导入。
- 常用链接保留卡片名称、简短用途和原始地址，删除评价性文案及无日期的“近日”更新说法。排除网站内明显指向其他单位的“纪检委”“国际交流合作”，以及指向学校机构总览的“网安学院”。“教务部”“计划财务部”各有两个不同地址，暂不选定其当前入口。
- 源网站没有可核验的树莓娘角色文字设定，本次不从图片推断身份、性格或经历。

## 更新

重新提取前核对网站路由和资料日期，逐主题审阅正文与链接。更新语料及来源清单中的源提交、文件摘要和提取日期，使用实际 `KeywordCorpus` 加载并检查代表性问题的前4条检索结果，再部署重启。清单仅用于来源追溯，不是加载器所需的协议文件。
